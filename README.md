# محاكاة صوت محرك السيارة

صفحة ويب تُصدر صوت محرك السيارة حسب **سرعتك الحقيقية** المأخوذة من الـ GPS، وتعمل **بدون إنترنت** بعد أول تحميل.
مفتوحة المصدر برخصة MIT (انظر `LICENSE`): انسخها أو خذ أي جزء منها كما تشاء.

## النشر على GitHub Pages
1. أنشئ مستودعاً عاماً جديداً على https://github.com/new (مثلاً باسم `teslasound`).
2. ارفع **كل محتويات هذا المجلد** مع الحفاظ على المجلدات `js` و`icons` والملف المخفي `.nojekyll`:
   - من المتصفح: **Add file → Upload files** واسحب كل شيء، ثم Commit.
   - أو من الطرفية:
     ```bash
     git init && git add -A && git commit -m "TeslaSound"
     git branch -M main
     git remote add origin https://github.com/USERNAME/teslasound.git
     git push -u origin main
     ```
3. من **Settings → Pages** اختر: *Deploy from a branch* ← الفرع `main` ← المجلد `/ (root)` ← **Save**.
4. بعد دقيقة تقريباً يصبح الموقع على: `https://USERNAME.github.io/teslasound/`

## الاستخدام
1. افتح الرابط من متصفح شاشة السيارة (أو أي متصفح)، واسمح بإذن **الموقع** إن طُلب.
2. اختر السيارة واضغط **تشغيل الصوت**، ثم ابدأ القيادة. (إن لم يوفّر متصفح السيارة الموقع، أو للتجربة وأنت واقف، استخدم **الوضع: يدوي**.)
3. لتثبيته كتطبيق: قائمة المتصفح ← *Add to Home screen / تثبيت التطبيق*.
4. تظهر عبارة «جاهزة للعمل بدون إنترنت» أسفل الصفحة بعد أول تحميل ناجح.

## تحديث الموقع بعد التعديل
ارفع الملفات المعدّلة، وغيّر رقم النسخة في `sw.js` (`teslasound-v1` ← `teslasound-v2`) ليتحدّث الجميع.

## ملاحظات
- الـ GPS والصوت يحتاجان HTTPS، وGitHub Pages يوفره تلقائياً.
- الموقع يُعالَج داخل الجهاز فقط ولا يُرسل لأي مكان.
- لا تتعامل مع الشاشة أثناء القيادة.
